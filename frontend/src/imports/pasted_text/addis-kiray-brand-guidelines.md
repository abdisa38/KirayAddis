# Addis Kiray — Brand Identity & Enterprise Design System

Design the complete visual foundation and reusable design system for a modern Ethiopian prop-tech platform called **Addis Kiray**.

## PRODUCT

Addis Kiray is a modern rental-property discovery and relocation platform designed specifically for Addis Ababa, Ethiopia.

The platform helps people:

* Find rental houses and apartments.
* Search by neighborhood and location.
* Search by budget.
* Search by property type.
* Search by lifestyle requirements.
* Find properties near work or school.
* Compare rental properties.
* Save favorite properties.
* Receive personalized property recommendations.
* Request property viewings.
* Communicate with landlords.
* Move from an existing home to a new home.
* Use AI-powered natural-language housing search.
* Discover verified landlords and properties.
* Report suspicious or fraudulent listings.

Landlords can:

* Create accounts.
* Verify their identity.
* Add rental properties.
* Upload property photographs and videos.
* Specify rent and rental conditions.
* Manage availability.
* Receive inquiries.
* Communicate with tenants.
* Manage viewing appointments.
* Track listing performance.

Administrators can:

* Manage users.
* Manage landlords.
* Review properties.
* Verify listings.
* Moderate content.
* Handle reports.
* Detect suspicious activity.
* Manage platform analytics.
* Review audit logs.

The design must support three major experiences:

1. Tenant
2. Landlord
3. Administrator

The product must eventually support both desktop and mobile experiences.

# BRAND POSITIONING

The brand should communicate:

* Trust
* Home
* Simplicity
* Location
* Accessibility
* Safety
* Community
* Modern technology
* Ethiopian identity
* Professionalism

The product should feel like a serious technology startup, not an old-fashioned real-estate agency.

It should NOT look like:

* A generic real-estate template.
* A luxury property-only website.
* A classifieds website.
* A social-media marketplace.
* A fintech application.
* A dark developer dashboard.
* A copy of Jiji or other existing marketplaces.

The experience must be welcoming to everyone from lower-income renters to premium-property renters.

The visual language should communicate:

**“Finding a home should be simple, trustworthy and personal.”**

# VISUAL STYLE

Use a modern:

**Clean + Human + Trustworthy + Map-first + Ethiopian PropTech**

* neon colors

# ACCESSIBILITY

Design according to modern accessibility principles.

Ensure:

* sufficient contrast
* visible keyboard focus
* readable typography
* touch-friendly controls
* clear labels
* error messages
* icons are not the only source of meaning
* status uses text plus visual indicators
* form fields have clear labels
* interactive elements have appropriate states

Target WCAG AA where practical.

---

# MULTILINGUAL READINESS

The product is intended primarily for Addis Ababa.

Design the system so that it can support:

* English
* Amharic

without breaking layouts.

Allow for longer or shorter text.

Ensure:

* buttons can accommodate different text lengths
* navigation can accommodate translation
* property information remains readable
* forms support Ethiopian names and addresses

Do not design English-only layouts that cannot adapt.

The final system should feel comparable to a polished modern prop-tech startup.

Prioritize:

1. usability
2. clarity
3. consistency
4. trust
5. accessibility
6. responsive behavior
7. visual polish

Do not sacrifice usability for visual effects.

The final visual identity should be recognizable as:

**Addis Kiray — a modern Ethiopian housing discovery platform.**

Create the brand foundation, visual identity, design tokens and reusable component system first.

Do not design the complete homepage or dashboards yet.

The purpose of this step is to establish the visual foundation that all future Addis Kiray screens will use.
