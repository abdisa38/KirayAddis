# Addis Kiray — Homepage / Landing Page

Continue the existing **Addis Kiray** design system and visual language already created.

Do NOT redesign or replace the existing brand identity.

Preserve the approved visual direction:

* Deep navy primary brand color
* Mint / teal accent
* Warm white and very light blue-gray surfaces
* Strong modern typography
* Generous whitespace
* Subtle borders
* Soft shadows
* Modern rounded cards
* Map-first visual language
* Property photography
* Verification badges
* Property Match Score
* Calm, trustworthy and premium-but-accessible visual style

The homepage must feel like a real production-ready Ethiopian prop-tech startup, not a generic real-estate template.

---

# PRODUCT

Addis Kiray is a rental-property discovery and relocation platform designed specifically for Addis Ababa.

The platform helps people find homes based on:

* location
* monthly budget
* property type
* bedrooms
* amenities
* lifestyle
* work/study destination
* commute time
* personal preferences

The platform also helps people who are:

* new to Addis Ababa
* relocating for work
* relocating for education
* changing from one rental house to another
* looking for affordable housing
* looking for premium housing

Landlords can list properties and manage inquiries, viewing requests and rental availability.

The homepage must clearly communicate this value proposition.
