# Addis Kiray — Property Details Page

Continue the existing Addis Kiray design system.

Do NOT redesign the brand.

Preserve the approved visual language:

* Deep navy
* Mint / teal
* Warm white
* Light blue-gray surfaces
* Modern typography
* Generous whitespace
* Subtle borders
* Soft shadows
* Professional rounded cards
* Realistic property photography
* Verification badges
* Match Score
* Map-first visual language
* Calm, trustworthy and accessible experience

This is the complete **Property Details experience** for Addis Kiray.

---

# PRODUCT CONTEXT

Addis Kiray is an Addis Ababa rental-property discovery platform.

Users discover properties through search, map, recommendations and AI.

When a user selects a property, the Property Details page must provide enough information for them to decide whether they want to:

* save it
* compare it
* contact the landlord
* request a viewing
* share it
* continue searching

The page must be optimized for trust, clarity and conversion.
